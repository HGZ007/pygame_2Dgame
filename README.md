# pygame_2Dgame

一个使用 Python 和 Pygame 编写的 2D 外星人入侵学习项目。

项目采用面向对象的方式拆分游戏设置、玩家飞船、子弹和外星人，通过这个小项目练习 Pygame 的事件循环、精灵编组、图像绘制与位置更新。

## 当前功能

- 创建 `1200 × 800` 的游戏窗口，并以最高 120 FPS 运行
- 使用方向键控制飞船左右连续移动
- 按空格键发射子弹，同时最多保留 3 发子弹
- 子弹飞出屏幕后自动从精灵组中移除
- 根据屏幕尺寸自动生成多行外星人舰队
- 外星人舰队持续向右移动
- 支持关闭窗口或按 `Q` 键退出游戏

## 操作方法

| 按键 | 功能 |
| --- | --- |
| `←` | 飞船向左移动 |
| `→` | 飞船向右移动 |
| `Space` | 发射子弹 |
| `Q` | 退出游戏 |

## 项目结构

```text
pygame_2Dgame/
├── 12.1.py       # 游戏入口、事件循环、舰队创建与画面更新
├── settings.py   # 窗口、飞船、子弹和外星人的参数设置
├── ship.py       # 玩家飞船的加载、绘制与移动逻辑
├── bullets.py    # 子弹精灵的创建、移动与绘制逻辑
├── alien.py      # 外星人精灵的加载与移动逻辑
├── ship.bmp      # 飞船图片素材（运行时需要）
└── alien.bmp     # 外星人图片素材（运行时需要）
```

## 运行环境

- Python 3
- Pygame

安装 Pygame：

```powershell
python -m pip install pygame
```

## 运行项目

克隆仓库：

```powershell
git clone https://github.com/HGZ007/pygame_2Dgame.git
cd pygame_2Dgame
```

请确认 `ship.bmp` 和 `alien.bmp` 位于项目根目录，然后运行入口文件：

```powershell
python 12.1.py
```

> 注意：当前远程提交尚未包含两个 BMP 图片素材。仅克隆远程仓库时，需要先把 `ship.bmp` 和 `alien.bmp` 放到项目根目录，否则 Pygame 会因找不到图片而无法启动。

## 主要参数

游戏参数集中保存在 `settings.py` 中：

| 参数 | 当前值 | 作用 |
| --- | ---: | --- |
| `screen_width` | `1200` | 窗口宽度 |
| `screen_height` | `800` | 窗口高度 |
| `ship_moving_speed` | `1.2` | 飞船移动速度 |
| `bullet_moving_speed` | `2` | 子弹移动速度 |
| `bullets_allowed` | `3` | 屏幕中允许存在的最大子弹数量 |
| `aliens_speed` | `1` | 外星人水平移动速度 |

## 程序运行流程

1. `12.1.py` 创建游戏、屏幕、飞船、子弹组和外星人组。
2. 主循环读取键盘和窗口事件。
3. 飞船、子弹和外星人分别更新自己的位置。
4. 游戏依次绘制背景、子弹、飞船和外星人舰队。
5. `pygame.display.flip()` 将这一帧显示到窗口中。
